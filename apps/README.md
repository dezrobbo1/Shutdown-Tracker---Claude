# Apps

Application workspace.

Implemented scaffolds:

- `console`: React/Vite Master Console shell for desktop-oriented review workflows.
- `mobile-pwa`: React/Vite Mobile Field App shell with a web app manifest.

Both apps currently use static synthetic scaffold data only. They do not call the API, store files, parse Project files, create execution records, generate export artifacts, or write back to Microsoft Project.

Run from the repository root after installing npm dependencies:

```text
npm test
npm run build
```
