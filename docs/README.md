# Documentation

This folder contains product, architecture, research, ADR, testing, security, and session-history notes for Shutdown Tracker.

No implementation is stored here. Documentation should preserve the product boundary that Microsoft Project remains the schedule authority and Shutdown Tracker remains the live execution and reporting authority.

[sessions](sessions/README.md) is the exception to "documentation describes the current state": entries there are dated records of individual working sessions and are not rewritten as the product moves on. Read the rest of `docs` for what is true now, and `sessions` for how it came to be that way.
