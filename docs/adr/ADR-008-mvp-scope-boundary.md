# ADR-008: MVP Scope Boundary

Status: Draft

## Context

The MVP must stay focused on execution tracking and reporting.

## Decision

Exclude Gantt view, CPM view, dependency-map UI, scheduler/recovery engine, resource levelling, AI prediction, custom dashboard builder, native mobile app, live Microsoft Project integration, and chat clone behavior.

## Consequences

- Scope-expanding features require explicit approval.
- Documentation and UI language must avoid implying scheduling ownership.
- Critical Work Package functionality must remain reporting-oriented.
