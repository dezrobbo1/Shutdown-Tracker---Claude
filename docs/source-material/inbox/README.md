# Source Material Inbox

Temporary landing folder for original Shutdown Tracker project source files before they are classified and moved into the permanent documentation structure.

## Upload process

1. Upload the source bundle or individual source files here.
2. Do not rename or edit the originals during upload.
3. After upload, classify each source as research or reference material.
4. Preserve original filenames and provenance where practical.
5. Update the repository source indexes/manifests as the material is organised.

This folder is an intake location, not the final documentation structure.
